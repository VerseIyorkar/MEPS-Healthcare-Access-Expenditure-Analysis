# Healthcare-Utilization-Analysis-in-SPSS



Prepared the MEPS 2023 dataset for analysis in SPSS using reproducible syntax. 
Variable and value labels were assigned using the MEPS codebook, measurement levels were defined,
and non-substantive response codes such as “Inapplicable,” “Refused,” and “Don’t Know” were designated as user-missing where appropriate.
This step is crucial because in cases where it's a recurring survey, this syntax can be shared with other analysts, so it is not done from scratch everytime
